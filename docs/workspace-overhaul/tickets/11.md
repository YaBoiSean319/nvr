# [Workspace 11] Add visual motion and AI zone editing

Canonical issue: https://github.com/YaBoiSean319/nvr/issues/60

## Parent

https://github.com/YaBoiSean319/nvr/issues/49

## What to build

Configure normalized rectangular detection regions directly on a representative camera frame, with accessible precision controls and truthful persistence.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] Draw, move, resize and remove rectangular zones with separate motion and AI scopes; preserve existing sensitivity, enablement and supported detector settings.
- [ ] Provide coordinate/time-independent keyboard and form alternatives so zone editing does not require dragging.
- [ ] Normalize and validate coordinates consistently with backend contracts; round-trip existing zones without scale drift and preserve full-frame semantics for an empty list.
- [ ] Handle missing frames and resolution/aspect changes explicitly without silently moving or corrupting existing zones; keep a usable coordinate fallback.
- [ ] Explicit Save reports actual persisted results, retains prior zones on validation/write failure and enforces administrator-only mutations.
- [ ] Test normalized round trips across display sizes, bounds/overlap policy as supported, disabled detectors, empty zones and unauthorized writes through actual configuration APIs.
