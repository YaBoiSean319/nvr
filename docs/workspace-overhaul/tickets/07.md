# [Workspace 07] Complete investigation tools, frame navigation and export marks

Canonical issue: https://github.com/YaBoiSean319/nvr/issues/56

## Parent

https://github.com/YaBoiSean319/nvr/issues/49

## What to build

Provide precise, uncluttered investigation controls and real media-backed marks/snapshots without regressing the existing playback contract.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] One shared transport provides play/pause and 0.25×/0.5×/1×/2×/4×/8×/16× speed; optional Skip Empty Periods skips only intervals with no recorded coverage across selected cameras.
- [ ] Frame stepping pauses and uses actual neighboring frame timestamps from the active camera, including variable/unequal frame rates; never approximate fixed-FPS stepping.
- [ ] Previous/Next Event retains simultaneous-event, scope, no-wrap and pause/play rules; motion/AI details remain reachable without per-tile clutter.
- [ ] Mark In/Out uses the shared playhead and is visible on the timeline; provide precise edits and Clear Marks with ordered/in-range validation.
- [ ] Default export range is the full applied investigation range; a single mark uses the corresponding range boundary for the missing mark. Empty/reversed ranges produce actionable errors.
- [ ] Complete marks open the contextual export drawer without losing investigation state; still snapshots use actual recorded source images and never treat a gap placeholder as fresh evidence.
- [ ] Discoverable shortcuts cover transport, seeking, marks, focus and closing panels; typing in inputs is never intercepted.
- [ ] Verify actual frames, gap/union coverage, event boundaries, snapshot audit/source time and mark persistence across membership/layout changes.
