# [Workspace 08] Ship sixteen-camera evidence exports and durable job controls

Canonical issue: https://github.com/YaBoiSean319/nvr/issues/57

## Parent

https://github.com/YaBoiSean319/nvr/issues/49

## What to build

Create, monitor and retrieve a bounded 16-camera evidence export from the investigation drawer while continuing to use the application.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] Accept up to 16 export cameras through validation, job creation, rendering and packaging; default individual videos plus shared grid in one ZIP, with camera subset, output choices and existing 1080p/4K options.
- [ ] Snapshot the underlying Auto/manual tile geometry/order, requested range, formats/timezone and optional supported audio at submission; temporary focus or later view changes cannot alter a job.
- [ ] Retain per-camera gap compression for individual MP4s, union-only gap compression for grid, last-frame/capture labels or dark initial gaps, source overlays/mappings, omissions, checksums and audit references.
- [ ] The drawer submits real jobs; a persistent jobs panel exposes truthful queue/progress/cancel/failure/completion/expiry and authenticated download across navigation/browser closure.
- [ ] Retry creates an auditable new attempt using the immutable request and revalidates source availability; interrupted renders never falsely report completion.
- [ ] Keep existing bounded workers/active queue, 24-hour range, source segment/byte limits, ZIP cap, free-space reserve, leases/holds and cleanup. Do not raise unrelated limits merely to accept 16 cameras.
- [ ] Decode generated 16-camera individual/grid outputs and inspect ZIP contents, ordering/layout, actual durations, shared source time, audio gaps and integrity verifier behavior.
- [ ] Test capacity/resource rejection, failed/cancelled/restarted jobs, unauthorized access, source retention during use and terminal reservation release.
