# [Workspace 04] Deliver adaptive Live quality and truthful tile recovery

Canonical issue: https://github.com/YaBoiSean319/nvr/issues/53

## Parent

https://github.com/YaBoiSean319/nvr/issues/49

## What to build

Keep Live efficient and understandable through real profile switching, compact tile actions and isolated camera failures.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] Auto chooses a compatible substream for grid viewing and main stream for focused viewing; expose Auto/Main/Sub overrides and truthful missing-profile/codec fallback.
- [ ] Viewing-quality changes do not alter recording or export source quality; bound concurrent profile transitions and release superseded viewers.
- [ ] Tiles show compact name/status and accessible enlarge/snapshot/audio/Playback/remove actions on hover, keyboard focus and touch; retain a separately reachable shortcut reference.
- [ ] Loading, stale, reconnecting and offline are distinct. An offline tile keeps its last dimmed image with capture/last-received timestamp and clear label, or a dark initial fallback.
- [ ] Use bounded automatic reconnect and manual retry without restarting unaffected feeds or creating connection leaks/retry storms.
- [ ] Audio starts muted, is capability/admin-policy gated and has at most one audible source. Snapshots use real displayed/source-time behavior and audit semantics.
- [ ] Test stream selection, unsupported profiles, initial/no-last-frame failure, outage/recovery, stale frames, focus changes and cleanup via observable viewer requests/media behavior.
