# [Workspace 02] Make Live camera selection drive Auto tiling and focus

Canonical issue: https://github.com/YaBoiSean319/nvr/issues/51

## Parent

https://github.com/YaBoiSean319/nvr/issues/49

## What to build

Compose a Live workspace by toggling cameras directly in the browser, with immediate Auto reflow, precise placement and uninterrupted existing streams.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] Sidebar camera click toggles membership with a visible selected check; new cameras append and load without Start or prior grid selection. Tile click changes control focus only.
- [ ] Auto uses columns × rows: 1→1×1, 2→2×1, 3–4→2×2, 5–6→3×2, 7–9→3×3, 10–12→4×3, 13–16→4×4 on widescreen, adapting to available space without stretching images.
- [ ] Zero selections shows a clear empty state; capacity is 16 with an actionable limit and no silent eviction. Existing viewers remain mounted through ordinary reflow.
- [ ] Drag a new camera onto a tile to replace it; dragging an existing camera swaps positions, without duplicate membership. Provide keyboard/touch placement alternatives.
- [ ] Double-click/Enlarge and Restore/Escape preserve underlying order and layout. Removing active/enlarged cameras yields a valid remaining focus/view.
- [ ] Auto is default; optional manual layouts and Return to Auto are secondary. Exceeding manual capacity returns to Auto with explanation while preserving membership.
- [ ] Exercise 0/1/2/3/4/6/9/12/16-camera behavior and assert stream lifecycle/connection counts, not only tile count.
