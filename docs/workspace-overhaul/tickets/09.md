# [Workspace 09] Replace camera forms with a complete inventory/detail workflow

Canonical issue: https://github.com/YaBoiSean319/nvr/issues/58

## Parent

https://github.com/YaBoiSean319/nvr/issues/49

## What to build

Manage cameras through a scalable searchable inventory and one detail editor, retaining every supported onboarding, configuration and archival operation.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] Inventory supports search, health, archived/history filtering, explicit bulk selection and a single selected-camera editor with progressive advanced options.
- [ ] Preserve manual address/username/password, brand, advertised endpoints/profiles, main/substream choices and real connection/credential tests with useful validated feedback.
- [ ] Preserve multicast/private-range discovery and CSV preview/apply; scans remain review candidates until intentional addition, and onboarding results never expose credentials.
- [ ] Expose recording enablement/modes, audio/AI settings, storage/group policy, retention/overrides and credential rotation with stable identity/media association and real explicit saves.
- [ ] Bulk supported edits show a change summary, bounded execution, per-camera results and selective retry; partial failure does not imply all rows succeeded.
- [ ] Archive stops collection while retaining searchable history; separate destructive deletion still requires archival, exact confirmation and no blocking holds/leases/exports.
- [ ] Prevent accidental loss of unsaved edits and verify operator/admin API boundaries and persisted state, not only visible form controls.
