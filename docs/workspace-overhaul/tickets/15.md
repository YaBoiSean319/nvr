## What to build

Polish the integrated app to the approved minimal workstation direction across desktop, tablet, phone, themes, keyboard and touch while preserving every completed workflow.

Design reference and implementation handoff: https://github.com/YaBoiSean319/nvr/tree/docs/workspace-overhaul-2026-10-22/docs/workspace-overhaul

## Acceptance criteria

- [ ] Review populated Live/Playback/inventory/settings/branding, empty/loading/no-footage/offline/recovery states and contextual drawers against the user-approved design reference.
- [ ] Verify 320/360/768/1024/1440 widths without horizontal page scrolling, clipping or tiny controls; keep purposeful local timeline panning, collapsed secondary panels and useful small-screen feed arrangements.
- [ ] Complete keyboard-only and touch journeys with visible focus, accessible names/status, keyboard alternatives to dragging, dialog/drawer focus restoration, shortcut reference and no input shortcut interception.
- [ ] Keep essential actions available without hover, clear selection versus active tile, consistent control placement and readable light/dark/system/branded appearance.
- [ ] Respect reduced motion, sufficient text/control/focus contrast and non-color status cues. Use concise feedback rather than filler cards, duplicated controls or permanently exposed advanced forms.
- [ ] Run real-browser role journeys for live selection/views, investigation/marks/export/jobs, visual editors and branding, including error recovery and unsaved edits.
- [ ] Replace obsolete markup/grid-selector assertions with observable workflow checks; preserve existing API/media/recording/evidence regressions and document actual verification limits.
