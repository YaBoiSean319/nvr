Grid tiles use the validated low-resolution profile when one was configured. Focus a tile for the main stream. Streams use your signed-in session and close when you stop viewing or leave this page.

Synchronized playback

Choose up to eight cameras and a time range up to 24 hours. Streams stay aligned to the same wall-clock time; timeline gaps distinguish expected idle, recording failure, uncertain coverage, and unindexed footage.

Exports run as bounded background jobs. Completed downloads contain one playable video per selected camera and metadata listing actual recorded intervals and missing time. Audio is omitted.
